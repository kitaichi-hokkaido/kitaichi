# 全道meeting 配布チラシ（クラファン伴走サポート）

- 対象：「全道meeting」に参加する道内の地域おこし協力隊 150〜200名
- 目的：KITAICHIのクラファン支援サービスを知ってもらい、無料相談の予約を5件獲得する
- 仕様：A4両面・200部／10月15日 道庁必着

## ファイル

| ファイル | 内容 |
|---|---|
| `flyer.html` | たたき台の元データ（ブラウザで開いて確認・編集） |
| `flyer.pdf` | 確認用PDF（1ページ目＝表面、2ページ目＝裏面） |

赤字の【要差替】【要確認】は仮の文言・数字です。

## 構成と意識変容

| 面 | ブロック | ねらい |
|---|---|---|
| 表 | タイトル「その『やりたい』、クラウドファンディングで全国の応援に変えませんか？」 | 協力隊の活動とクラファンを結びつける |
| 表 | 写真 | 活動の現場感を出す |
| 表 | よくある悩み → 4ステップの伴走サービス | ①クラファンをサポートしてくれる会社があると知る |
| 表 | KITAICHIについて（実績数字） | ①信頼感 |
| 表 | 無料相談CTA（参加者限定・先着5名）＋QR | ③予約してもらう |
| 裏 | 協力隊のクラファン事例 ×3（課題／挑戦／結果／本人の声） | ②自分事にする |
| 裏 | 下部に再度CTA＋QR | 裏面だけ見た人も予約につなげる |

## 差し替えが必要な素材・情報

- [ ] メイン写真（横長、350dpi推奨）
- [ ] ロゴデータ
- [ ] 正式社名・所在地・設立年・紹介文
- [ ] 実績数字（支援件数・累計支援額・達成率）
- [ ] サービス内容・料金体系の書き方（成功報酬型／初期費用0円 などを載せるか）
- [ ] 連絡先（メール・電話・Web）
- [ ] 予約フォームURL → QRコード（「全道meeting経由」と分かるURLパラメータ付きにすると効果測定できます）
- [ ] 受付期限
- [ ] 事例3件：地域名・テーマ・課題・挑戦・支援総額・支援者数・達成率・本人コメント・写真（掲載許諾も確認）

## スケジュール目安（10/15 道庁必着から逆算）

| 期限 | 作業 |
|---|---|
| 〜10/1 | 素材・情報を揃え、原稿確定 |
| 〜10/5 | デザイン仕上げ・社内校正 |
| 10/6 | 入稿（ネット印刷の通常納期 3〜5営業日を想定） |
| 〜10/10 | 納品・検品 |
| 10/11〜12 | 道庁へ発送（余裕を持って必着日の数日前に届く便で） |
