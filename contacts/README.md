# 名刺管理

名刺の内容をスプレッドシート（CSV）にまとめて管理するためのディレクトリです。

## ファイル構成

```
contacts/
  README.md
  meishi.csv     # 名刺台帳（Excel / Google スプレッドシート等で開けるCSV。正データはこちら）
  meishi.xlsx    # 上記CSVを見やすく整形したExcelスプレッドシート
```

`meishi.xlsx` は `meishi.csv` から生成した閲覧・共有用のファイルです。新しい名刺を追加したときは、`meishi.csv` を更新したうえで `meishi.xlsx` も作り直してください。

## 使い方

1. `meishi.csv` は Excel や Google スプレッドシートにそのままインポート（または直接開く）できます。
2. 新しい名刺を追加する場合：
   - 名刺の写真をこのリポジトリのやり取りに添付し、「この名刺を登録して」のように依頼してください。写真から氏名・会社名・連絡先などを読み取り、`meishi.csv` に1行追加します。
   - 手入力する場合は、下記の列に従って1行追加してください。

## 列の説明

| 列名 | 内容 |
|------|------|
| 登録日 | 名刺を登録した日（YYYY-MM-DD） |
| 氏名 | 氏名 |
| フリガナ | 氏名のふりがな |
| 会社名 | 会社名・団体名 |
| 部署 | 部署名 |
| 役職 | 役職 |
| 郵便番号 | 郵便番号 |
| 住所 | 住所 |
| 電話番号 | 固定電話番号 |
| 携帯電話 | 携帯電話番号 |
| FAX | FAX番号 |
| メールアドレス | メールアドレス |
| URL | 会社・個人のWebサイトURL |
| 備考 | その他メモ |

## 注意事項

- 名刺には個人情報が含まれるため、取り扱いに注意してください。
- 読み取れない項目は空欄のままで構いません。
